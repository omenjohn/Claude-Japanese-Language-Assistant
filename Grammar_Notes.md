[です]
form: noun/adjective + です
meaning: polite copula ("is/am/are")
familiarity: practiced
notes: user occasionally appends です after ません — watch for this

[ます/ません/ませんか]
form: verb stem + ます (affirmative) / ません (negative) / ませんか (negative question/invitation)
meaning: polite verb ending
familiarity: practiced
notes: ませんです is a recurring error — ません is already complete, does not take です
       ませんか feels less polite to user due to prior exposure — clarified it's same register, different function (invitational)

[は — topic marker]
form: noun + は
meaning: marks the topic of the sentence
familiarity: practiced
notes: user using correctly; distinction from が not yet drilled

[を — object marker]
form: noun + を
meaning: marks the direct object of a verb
familiarity: introduced
notes: user produced correctly without instruction; occasionally dropped under load

[に — time/direction marker]
form: noun + に
meaning: marks specific time references and direction
familiarity: introduced
notes: introduced in context of 金曜日に; contrast with は as topic not yet drilled

[て-form — verb chaining]
form: godan: く→いて、ぐ→いで、す→して、む/ぬ/ぶ→んで、る/つ/う→って | ichidan: stem + て
meaning: connects sequential or related actions
familiarity: introduced
notes: user attempted て-form connection but wrote 蓮 (lotus kanji) instead of 話して — corrected and reproduced correctly on second attempt

[い-adjectives]
form: stem + い (plain) | stem + くない (negative) | stem + かった (past) | stem + くなかった (past negative)
meaning: adjectives that conjugate by replacing い with く before endings
familiarity: introduced
notes: user has the pattern; needs repetition to automate
       common error: 高くじゃない (mixing い and な patterns) — corrected immediately
       好き looks like い but is actually な — flag if it comes up
       examples known: かわいい、暑い、寒い、早い、高い、面白い

[な-adjectives]
form: stem + な (before noun) | stem + だ (predicate) | stem + じゃない (negative) | stem + だった (past) | stem + じゃなかった (past negative)
meaning: adjectives that use な when modifying nouns directly; swap だ for conjugation in predicate
familiarity: introduced
notes: user grasped modifier vs predicate position quickly
       examples known: 好き、静か、上手、下手

---

[いる/ある — existential verbs]
form: [living thing]がいます | [non-living thing]があります
meaning: expresses existence; いる for animate, ある for inanimate
familiarity: confident
notes: user confirmed aware; produced います correctly for cats; は/が distinction in existential sentences noted

[する/します — to do]
form: する (plain) | します (polite) | しない (negative) | しません (polite negative) | した (past)
meaning: generic action verb; combines with nouns to make compound verbs (e.g. 運動する)
familiarity: confident
notes: user confirmed aware; produced 運動する naturally

[こと — nominaliser]
form: verb (dictionary form) + こと
meaning: turns a verb phrase into a noun phrase
familiarity: confident
notes: user using correctly in wild (運動することが大好き); also aware of ことがある、ことができる expressions

[で — location/means marker]
form: noun + で
meaning: marks location of an action, or means/method by which something is done
familiarity: confident
notes: user has a solid mental model (で as "how/by means of"); covers 公園で、日本語で、バスで naturally
